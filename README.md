A 4 KB Python chess engine: alpha-beta search with quiescence, a transposition table, killer-move ordering, value-based move ordering and check extensions, on a compact 0x88 board with incremental evaluation. Practice Elo 1191 on trial-0, trial-1 and trial-2 against the house gauntlet (2 wins, 1 draw, 3 losses each).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 python3 main.py
```
